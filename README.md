# SmartQA AI – AI-Powered Smart Home Assistant & Quality Engineering Platform

## Overview

SmartQA AI is an AI-powered smart home assistant combined with an automated AI Quality Engineering platform. It uses Retrieval-Augmented Generation (RAG) to provide context-aware answers from product documentation and technical manuals.

The platform focuses on evaluating and improving AI application quality through automated LLM evaluation, hallucination detection, security testing, API automation, and performance monitoring.

## Key Challenges Addressed

1. **AI Hallucination Detection:** Evaluating AI-generated responses for accuracy, relevance, and faithfulness using automated LLM evaluation frameworks.

2. **AI Security and Reliability:** Identifying prompt injection, jailbreak attempts, sensitive information leakage, and application failures through automated testing.

3. **Continuous AI Quality Monitoring:** Maintaining golden datasets, tracking evaluation scores, monitoring latency, and detecting quality regressions through CI/CD.

## Technology Stack

- Ollama, Llama 3.2
